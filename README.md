# 🏅 小学运动会检录与成绩更正系统

老师报名 → 检录员现场确认到场 → 裁判录入成绩（电子计时 / 手记）→ 总裁判复核分歧、漏记、补赛与更正 → 公示屏只展示**已确认且已发布**的榜单。

- **后端**：Rust + Axum 0.7 + SQLx 0.8 + SQLite（单二进制，同时托管前端与 API）
- **前端**：Svelte 4 + Vite 5
- **计时器**：本地模拟（一次生成电子计时与手记两条原始记录，可强制制造分歧）
- **启动**：`./start.sh` 一条命令（自动装依赖、构建、运行）

## 快速开始

```bash
./start.sh                 # 然后浏览器打开 http://localhost:8080
PORT=9000 ./start.sh       # 换端口
RELEASE=1 ./start.sh       # release 编译
./start.sh --verify        # 启动前先跑端到端验证（35 项断言）
```

系统内置 4 个演示身份（右上角切换）和演示数据：

| 身份 | 姓名 | 职责 |
|---|---|---|
| 老师 `teacher` | 王老师 | 学生/项目建档、项目报名 |
| 检录员 `clerk` | 李检录 | 按项目/组别/轮次登记到场或缺席、新建补赛轮次 |
| 裁判 `referee` | 赵裁判 | 电子计时/手记录入、本地模拟计时、漏记补录、发起更正 |
| 总裁判 `head_referee` | 孙总裁 | 分歧裁决、漏记/补赛确认、更正二审、发布榜单、审计 |

重置为初始演示数据：`curl -X POST http://localhost:8080/api/admin/reset -H "X-User-Id: 4"`

## 业务规则（系统强制执行）

1. **同一学生同一轮次不能重复检录** —— 重复提交返回 `409 Conflict`；缺席者不参与排名，也不能录成绩。
2. **电子计时 vs 手记**：两条原始记录均**不可变**。差值在容差内（径赛 0.2 秒 / 田赛 0.02 米）自动确认并采用电子计时；**超容差不自动选任何一个发布**，生成复核单由总裁判裁决（必须填写依据，裁决值只能是电子值或手记值）。
3. **漏记补录 / 补赛轮次**：结果一律为「待复核」，总裁判确认后才可进入榜单；补赛以独立轮次管理，不与原轮次冲突。
4. **成绩更正**：必须填写原因，且**必须由申请人之外的另一人审核**（本人审核返回 `403`）；通过后仅更新成绩，**重新发布榜单**后公示屏才变化。
5. **榜单版本化**：每次发布生成新版本快照，**旧榜单永久保留**；原始计时记录与更正链（原因、申请人、审核人、新旧值）随时可溯源。
6. **并列名次**：按竞赛排名 `1,1,3` 规则处理（并列后名次顺延），径赛时间越小越好、田赛距离越大越好。
7. **公示屏**（5 秒自动刷新）：只显示已发布版本中已确认、到场的成绩；待复核、缺席、被驳回、未发布的数据一律不出现。

## 端到端验证

```bash
./verify.sh
```

自动构建并启动临时服务（独立临时数据库、随机端口），覆盖：重复检录拒绝、缺席不排名、一致自动确认/分歧人工裁决、漏记与补赛复核、更正双人审核、并列名次、更正后榜单更新、旧榜单与原始计时可查、公示屏只显示已发布数据。

## 主要 API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/checkins` | 检录（重复检录 409） |
| POST | `/api/timing` | 录入电子/手记原始记录 |
| POST | `/api/timer/simulate` | 本地模拟计时器（`force_dispute` 可制造分歧） |
| POST | `/api/results/missing` | 漏记补录（待总裁确认） |
| GET | `/api/review/queue` | 总裁判复核队列 |
| POST | `/api/review/disputes/:id` | 分歧裁决（必填依据） |
| POST | `/api/review/results/:id/confirm` `.../reject` | 漏记/补赛确认或驳回 |
| POST | `/api/corrections` / `/api/corrections/:id/review` | 更正申请 / 另一人审核 |
| POST | `/api/rounds/:id/leaderboard/publish` | 发布新版本榜单 |
| GET | `/api/rounds/:id/leaderboard/latest` `/versions` `/api/leaderboard/:vid` | 最新榜 / 版本列表 / 历史快照 |
| GET | `/api/results/:id/trace` | 成绩溯源（原始记录 + 更正链） |
| GET | `/api/public-board` | 公示屏数据 |

所有写接口通过请求头 `X-User-Id: <用户id>` 识别操作人并做角色鉴权。
